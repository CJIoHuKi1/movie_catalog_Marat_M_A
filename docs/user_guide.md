# Руководство пользователя

## Главная страница

На главной странице отображаются все фильмы в виде карточек. Каждая карточка содержит:
- Название фильма
- Режиссёра и год
- Жанр
- Оценку звёздами
- Кнопки: Подробнее, Редактировать, Удалить

## Поиск и фильтрация

- В поле **«Поиск по названию»** введи часть названия фильма
- В выпадающем списке **«Все жанры»** выбери нужный жанр
- Нажми **«Найти»** — список фильмов обновится

## Добавление фильма

1. Нажми кнопку **«Добавить фильм»** в меню
2. Заполни все поля (обязательные помечены звёздочкой)
3. Нажми **«Сохранить»**

## Редактирование фильма

1. На главной или детальной странице нажми кнопку с карандашиком **✏️**
2. Измени нужные поля
3. Нажми **«Сохранить»**

## Удаление фильма

- Нажми красную кнопку с корзиной **🗑️** и подтверди удаление

## Детальная страница

Содержит полную информацию о фильме: описание, постер (если добавлена ссылка), жанр, оценку.
