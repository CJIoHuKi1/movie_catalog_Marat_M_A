 Анализ требований к проекту «Каталог фильмов с оценками»

 1. Проблема

Пользователям сложно хранить список просмотренных фильмов и помнить, какую оценку они поставили. 
Нет простого инструмента для каталогизации фильмов с возможностью поиска и фильтрации, 
а также с гибкой системой оценок (не только целые числа, но и десятичные дроби).

 2. Целевая аудитория

- Кинолюбители, которые хотят вести учёт просмотренных фильмов
- Люди, которые забывают, какой фильм и когда смотрели
- Те, кто хочет делиться подборками фильмов с друзьями
- Пользователи, которым важна точная оценка (например, 7.5 из 10)

 3. Функциональные требования

1. Пользователь может добавить фильм с указанием названия, режиссёра, года выпуска, жанра, оценки (1–10 с шагом 0.1), описания и ссылки на постер.
2. Пользователь может просмотреть список всех фильмов в виде карточек с постерами и краткими описаниями.
3. Пользователь может открыть детальную страницу фильма с полной информацией.
4. Пользователь может редактировать информацию о фильме.
5. Пользователь может удалить фильм.
6. Пользователь может искать фильмы по названию (частичное совпадение).
7. Пользователь может фильтровать фильмы по жанру.

 4. Нефункциональные требования

- Веб-интерфейс с адаптивным дизайном (Bootstrap 5)
- Хранение данных в SQLite (не требует отдельного сервера БД)
- Время ответа сервера не более 1 секунды при стандартных операциях
- При первом запуске база данных автоматически заполняется тестовыми фильмами
