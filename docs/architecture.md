# Архитектура приложения

## Общая схема
Клиент (Браузер)
↓
Flask (app.py)
↓
SQLite (movies.db)

text

## Компоненты

### 1. Flask (app.py)
Обрабатывает HTTP-запросы, рендерит HTML-шаблоны, вызывает функции из models.py.

### 2. Модель данных (models.py)
Работа с базой данных SQLite. Содержит функции:
- `init_db()` — создание таблицы
- `get_all_movies()` — получение всех фильмов с фильтрацией
- `add_movie()` — добавление
- `update_movie()` — обновление
- `delete_movie()` — удаление
- `validate_movie_data()` — валидация

### 3. Шаблоны (templates/)
HTML-страницы с использованием Bootstrap 5 для стилизации.


## Маршруты

|     Маршрут    |   Метод   |             Описание              |
|----------------|-----------|-----------------------------------|
| `/`            | GET       | Главная (список + поиск + фильтр) |
| `/movie/<id>`  | GET       | Детальная страница                |
| `/add`         | GET, POST | Добавление фильма                 |
| `/edit/<id>`   | GET, POST | Редактирование                    |
| `/delete/<id>` | POST      | Удаление                          |

## Почему выбраны эти технологии?

- **Flask** — лёгкий и подходит для небольших проектов
- **SQLite** — не требует отдельного сервера, простота
- **Bootstrap** — быстрый красивый интерфейс без сложного CSS
- **pytest** — стандартный инструмент для тестирования Python
